# Předlohy od dětí

Sem patří fotky nebo skeny kreseb. Na každou postavu stačí **jeden obrázek**, jak stojí (zepředu nebo z boku). Animaci (chůzi, skok, otočení) doplní hra sama z jednoho obrázku.

Pojmenujte soubory podle postavy, například:

- `postavy/dogman.jpg` (ve skafandru, protože většina hry je pod vodou)
- `postavy/cunas.jpg` (hotovo)
- `postavy/bobanek.jpg` (hotovo)
- `postavy/petulka.jpg` (hotovo)
- `postavy/chobotnice.jpg`
- `postavy/rybka-robot.jpg`
- `postavy/meduza.jpg`
- `postavy/sef.jpg`
- `postavy/zuzu.jpg`
- `postavy/ema.jpg`
- `prostredi/pristav.jpg`
- `prostredi/dno-more.jpg`
- `prostredi/ponorka.jpg` (hotovo, leží v postavy/ponorka.png)
- `komiks/uvod-panel-1.jpg`

Tipy pro kreslení: velké jednoduché tvary, silné obrysy, pár výrazných barev. Postava na bílém papíře bez pozadí se převádí nejlépe.

Fotky ukládejte rovnou jako obrázky (.png nebo .jpg), ne přes MarkText. Jak kresbu převést do hry, popisuje hlavní README v kořeni projektu.
